# Project Goal

The goal is to overwrite default Minecraft combat and add RPG elements.

## Visual Systems
- Reskin entities using BetterModel
- Send damage number packets
- Modify the scoreboard to display stats
- Change nametags to display entity health and level
- Modify the player action bar to display volatile stats

## Data Systems
- Add player level scaling
- Overhaul damage calculations
- Redesign the mob immunity table to support attack speed scaling
- Create modifiers and inject them into the damage pipeline
    - Overwrite vanilla equipment
    - Overwrite vanilla enchantments
    - Add custom buffs
    - Add custom equipment
    - Add custom enchantments
